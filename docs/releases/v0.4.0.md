- 새 `rename <remote-path> <new-name>` command로 같은 folder 안에서 file 또는 folder의 이름을 바꿀 수 있다.
- 새 `move <remote-path> <destination-directory>` command로 기존 folder로 file 또는 folder를 옮길 수 있다. destination `/`(root)를 지원하고, 자기 자신이나 descendant로의 이동과 folder가 아닌 destination은 mutation 전에 거부한다.
- `rename`과 `move`는 `resourceId`를 유지하며 mutation endpoint를 한 번만 호출한다. 이미 목표 이름이나 위치면 mutation 없이 `action: "unchanged"`로 성공한다.
- timeout, 5xx, 429 또는 잘못된 성공 body로 결과가 불확실하면 mutation을 반복하지 않고 이전/새 path를 같은 ID로 조회해 확인하며, 확정할 수 없으면 exit 6 `MUTATION_UNCONFIRMED`로 보고한다.
- `--json` envelope의 `action`에 `renamed`, `moved`, `unchanged`가 추가되고 human output에 `Renamed`, `Moved`, `Already named`, `Already in destination` 문장이 추가됐다.
- path를 확정할 때 요청한 spelling이 아니라 MYBOX가 실제 저장한 canonical spelling을 사용해, Unicode fallback과 canonical 충돌 상황의 확인 결과가 서버 상태와 일치한다.
